# VanillaStats

Open source tooling for collecting and displaying vanilla Minecraft player stats.

- 🔌 **vanillastats-paper** — Paper plugin that collects stats from your server
- 🔧 **vanillastats-api** — Backend API storing and serving player/server stats
- 🌐 **vanillastats-web** — Website for viewing player and server stats
