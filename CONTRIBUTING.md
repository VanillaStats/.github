# Contributing to VanillaStats

Thanks for your interest! A few guidelines:

- Open an issue before starting work on a larger change, so we can discuss the approach first
- Branch naming: `feature/short-description` or `fix/short-description`
- Keep PRs focused — one feature/fix per PR
- Make sure the project builds locally before submitting

See the README in the specific repo you're working on.
